# 万仙之一 · 浮生问道

中文单机修仙人生模拟。出身、际遇和寿元构成处境，玩家决定追求什么、与谁相处，以及怎样回应旧日的承诺。修炼和经营仍有真实规则，但不再要求先学会一整套资源管理。

真实源码：`C:\dev\wanxian-life`。唯一源码仓库：`https://github.com/happyivanencoding/wanxian`，与《一方洞天》《修仙宗门》不共用代码或存档。

## 开始游玩

公网发布入口：**https://happyivanencoding.github.io/wanxian/**。发布分支为 `gh-pages`，源码分支为 `main`；实际部署验收记录见 ProjectMemory 当前交接。

公网版使用浏览器本地概率引擎，不需要账号、API Key 或家中电脑在线。它不是云存档：不同浏览器、设备及网址之间不自动同步。当前使用 **v2 测试存档**。v1 不再读取或迁移，旧版本导入将被拒绝；直接开启新人生即可。v2 存档仍可导出／导入，但没有跨设备自动同步。

默认出生只需选择节奏，姓名可以留空。家世与地域随机，从零岁开始；自选出身、灵根、道路、种子及十六岁快速启程收在「自选出身与开局」。半小时／一小时是按800年估算的播放节奏，不保证固定时刻结束人生。

## 连续的人生

新生没有预设朋友。人在渡口、采药、行旅、交易、师承和争夺中相识；实际年龄、境界、法宝、初见地点和愿望成为这个人的状态。有人只是相识，有人成为朋友、恩人、道侣或仇敌。只有当前v2人生的已认识人物与往事会在保存和继续时保留。

人生主场景始终留在原位。「相识的人」不再占用主页一整块区域，而是由往事旁的人物图标打开名单和回忆弹窗；加入宗门后，旁边还会出现可直接打开门中近事的小盾牌。顶部「行事」只常显修行、山河、相识的人与人生记录等必要入口；仙门、洞府和行囊归入可展开的「修行细务」。新角色拜入师门靠地方故事里的引荐，四段连续奇遇由生活中出现的线索邀请，**不会作为可主动领取的任务列表**。手动远行依旧按世界规则收路费；剧情中的同行邀请可由同行者负担路费。抽屉关闭后回到原来的阅读位置和播放状态。

六岁后可选择问道、远游、相守、自处。日常照料按真实生计、身心与准备安排修行，使用已有丹药照料伤势，按实际概率尝试普通突破；也可切回七种手动重心。重要决定和最后叩问天门由玩家亲选。不设置飞升率上限、死亡配额或强制失败结局。

## 人各有路，恩仇有因

NPC有独立的修炼速度、资源、当前法门瓶颈、冲关时间与机缘。有人得到传承后加速，有人长期停在炼气或筑基，有人受伤后多年无法冲关。新相识者可能是同龄人，也可能早已是金丹、元婴前辈；不按主角境界同步升级。主角也会经历有真实修炼倍率与冲关影响的顿悟和瓶颈，参悟、历练、准备与资源继续有效。

夺取、失约或争夺历史遗物可能留下具体仇怨。存活的敌人可以追来，战斗胜算同时使用境界、战技、体魄、资质与法宝。迎战、脱身、赔偿和已有师门／强者的庇护是不同选择；危险会事先显示，失手可能真正陨落并记录实际仇敌。和解不凭空变成朋友，死人也不会再次追杀。

原20个条件式人生事件和三条命途继续运作，但只使用已经相识的人及实际旧事。援助、家族长约、剑谱约定、传承与个人行记仍有真实后果；不假定每局一定结识所有关键人物。

## 五洲世界与天门纪

`docs/WORLD_HISTORY.md`构建玄川五洲的前史、二十师承、十五家族和十二段「天门纪」。另外 `src/game/regional.ts` 为五洲分别提供**五幕地方线**（相遇、地方纷争、师承、出行、旧地回响）；青衡泉契、沧溟药路、玄朔剑冢、赤曜迁徙和玉京名册互不复制。世界历史使用独立历年和随机状态，玩家搬到新地方后，遇见的人和地方故事随之变化。

从白石夜潮、七桥竞渡、照夜开冢，到旧院再开、五洲易主与天门重光，历史抉择的按钮改成「帮谁做什么」，不再写笼统的「支持某联盟」。门派身份会改变你在当地历史事件中的贡献得失。玩家仍可公开线索、带走所得或置身事外；干预能改变后续历史概率，不保证获胜。

历史已经影响实际修炼环境、收入、物价、路费、风险、门派年例与入门条件。势力可能鼎盛、困守或闭山；主页和山河展示当前局面与已发生的结果，不预告未来章节和奖品。

五洲以五个可迁居锚点承载；五个联盟代表地区势力变化，二十门派并未各自运行独立战争AI。十五家族是身份与事件来源，不是完整族谱模拟。十二段历史和人物事件是有限编写内容，不宣称无限剧情或完整开放世界。

## 行囊与修仙深度

新得到的可研读功法直接学会；比当前装备更高品阶的法宝自动佩用，仍可手动换装。裂纹玉片、听潮铃、照夜星砂、残鞘和无字铜牌等遗物初见只显示已知事实，没有猜谜式使用／出售按钮。到了相关历史场景便自然回应，留下认知、修行或介入历史的实际影响；不重复发奖，也不在读档时重新兑现。

每年三次主动行动仍可用于买卖、行旅、洞府或主动精修，但无需用完。**宗门委托、门内争议、传功与升任已经接进人生故事**：20座山门各有自己的实地委托和内部矛盾，师门人物随经历相识；任务选择可获得贡献、改变附近势力，贡献与境界达到要求会自然升职。技法传授也会在积累足够贡献以后作为单独的故事邀请出现；原手动门务只在高级折叠区保留。五地域二十门派、三种持续境界准备、四段三幕机缘、五类洞府设施、四张丹方、单槽法宝、年谱、传记、收藏、三个手动槽和最多30卷前尘保留。

## 时间与保存

年份进度走满才结算，1×／2×／4×／8×只改变现实等待；手机底部固定年份进度与暂停／继续，不再保留已删除导航的58px空位。故事选择不会提前显示数值奖励，做完以后年谱才用不同颜色显示实际得失，避免数字重复出现。没有直接跳年、离线补算或定时强制结局。抽屉、管理弹窗、重要抉择、连续机缘和隐藏浏览器标签暂停模拟。空格暂停／继续，Escape关闭当前弹窗。

当前仅支持 v2 存档（`wanxian-life:profile:v2`）。旧版本不再自动加载或迁移，导入只接受现行结构；缺少世界状态等当前必需字段的文件会被拒绝，不覆盖当前人生。旧版浏览器本地键不会由本版读取。

## 剧情一致性与修炼节奏

已将五洲初逢及二十宗门的欢迎、委托、守旧选择改成与当地事件相关的具体行动和对应结果；高阶修士入门按身份受邀传道，不再被当作外门新人。低两个以上大境界的旧敌会通过传话、解释或求偿解决旧怨，而不是强迫高阶修士决生死。旧友离世后出现的是遗稿处理，不再发生不可能的当面救治。

普通选项不提前展示奖励，但消耗灵石的选项始终展示具体费用；不够时显示所需、现有和缺口。涉及长期供养的决定显示往后每年的灵石支出，传功邀请显示贡献费用。探索邀请只扣一次行装费。突破面板保留本次概率与真实费用，不展示概率上限的内部数值。

炼气至化神的修为要求调整为170／480／1200／2850／6500。30个固定种子模拟的飞升年龄中位数约827岁、最快496岁，30局均成功飞升；不设置最低飞升岁数，资质、际遇、选择和随机结果仍决定最后去向。

## 本地开发

```powershell
cd C:\dev\wanxian-life
npm install
npm run dev
```

固定入口 `http://localhost:5188`。双击 `启动万仙之一.vbs` 使用生产预览；先运行 `npm run build` 更新构建。同Wi-Fi手机试玩可用 `tools/start.ps1 -Lan`，它不安装服务，也不等于公网发布。

```powershell
npm run build
npm test
npm run preview        # 与 dev 二选一，占用相同5188端口
npm run test:browser   # 连续交互、人物历史、现行v2存档和两主题多尺寸回归
npm run test:ui        # 仅两主题多尺寸视觉与可用性检查
npm run test:life      # 同一浏览器套件的发布验收模式，入口由APP_URL指定
npm run build:pages    # 输出 .artifacts/pages-site，含 /wanxian/ 子路径
```

实际公网发布后检查：

```powershell
$env:APP_URL='https://happyivanencoding.github.io/wanxian/'
npm run test:life
Remove-Item Env:APP_URL
```

测试使用独立浏览器上下文和虚构存档，不读取或覆盖玩家的实际浏览器存档。截图及报告位于 `.artifacts`，不进入源码提交。

## 发布

先完成验证、提交并推送 `main`，然后运行：

```powershell
powershell -ExecutionPolicy Bypass -File tools\publish-pages.ps1
```

脚本从干净源码构建静态站点，以普通快进提交发布到同仓库 `gh-pages`，不强推、不上传密钥或测试存档。首次需将 GitHub Pages 来源配置为该分支根目录。分支推送不等于公网验收完成，仍须检查 Pages 状态、实际页面、图片、创建人生和刷新续玩。

本次公网使用独立静态托管；未新增VPS容器、Cloudflare路由、家中常驻服务或后台智能体。Pages模式明确关闭不存在的模型后端，不让404请求影响游玩。

## 可选本地 StartLux

本地 dev／preview 仍可通过 `.env.local` 配置 `STARTLUX_KEY_FILE` 或 `STARTLUX_API_KEY`，参见 `.env.example`。密钥仅由服务器读取，不进入前端、存档或Git。

StartLux只对已有的合法普通机缘或具体NPC互动候选排序。后台准备未及时完成时，年界或点击立即采用本地结果；迟到回答丢弃。它不生成任意剧情、发放奖励或代替人生决定。公网Pages版不启用该可选服务；两个模式使用同一套核心模拟规则。

## 代码入口

- `src/game/engine.ts`：确定性结算、时间、主动操作、破境和存档中的真实状态。
- `src/game/history.ts`、`relationships.ts`、`cultivation.ts`：世界历史、势力后果、自然相识、追索冲突与独立修行际遇。
- `src/game/lifelines.ts`、`story.ts`、`events.ts`：人物因果、生活方向、原有命途和事件。
- `src/game/sect-life.ts`：二十门派独立门中生活、任务、传功、贡献与历史影响。
- `src/game/progression.ts`、`sects.ts`、`expeditions.ts`：持续准备、门派和三幕机缘。
- `src/components/ActionDrawer.tsx`、`src/ContinuousLife.css`、`src/pages/Journey.tsx`：常驻人生、就地行事与紧凑布局。
- `docs/DESIGN.md`：实现与边界；`docs/WORLD_HISTORY.md`：世界主干；`docs/WORLD.md`：地域、师承与原有秘境。
