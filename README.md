# 万仙之一 · 浮生问道

中文单机修仙人生模拟。出身、际遇和寿元构成处境，玩家决定追求什么、与谁相处，以及怎样回应旧日的承诺。修炼和经营仍有真实规则，但不再要求先学会一整套资源管理。

真实源码：`C:\dev\wanxian-life`。唯一源码仓库：`https://github.com/happyivanencoding/wanxian`，与《一方洞天》《修仙宗门》不共用代码或存档。

## 开始游玩

公网发布入口：**https://happyivanencoding.github.io/wanxian/**。发布分支为 `gh-pages`，源码分支为 `main`；实际部署验收记录见 ProjectMemory 当前交接。

公网版使用浏览器本地概率引擎，不需要账号、API Key 或家中电脑在线。它不是云存档：不同浏览器、设备及网址之间不自动同步。原本地人物可以在原入口「存档」导出 JSON，再在公网入口导入；导入前会校验并要求确认。

默认出生只需选择节奏，姓名可以留空。家世与地域随机，从零岁开始；自选出身、灵根、道路、种子及十六岁快速启程收在「自选出身与开局」。半小时／一小时是按800年估算的播放节奏，不保证固定时刻结束人生。

## 现在的核心玩法

**人生主页**展示最近真实发生的事、四位同世人物和已留下的往事。点人物查看当前状态与共同经历；故人离世或飞升后，其名字和往事仍保留。

六岁后可选择「问道、远游、相守、自处」。成年后，日常照料依实际体魄、道心、灵石和准备情况安排休养、营生及修行，按原概率尝试普通突破。它不代答人生转折，也不购买物品、加入宗门或自动探险。随时可展开具体年度重心，切回手动安排；旧存档默认保留原手动模式。

新增 **20个条件式人生事件**，覆盖渡口相约、共同丹药、家族长约、剑谱分歧、相聚与送别，以及书册、师承、后来者和旧地的变化。事件需要实际年龄、人物状态和前事，单次发生，不宣称每个人一定遇到全部事件。

选择有具体后果：赠药改变指定同道的后续成长和风险，但不保证其生存；家族长约带来收入并占用修炼时间，续约时可以解除；信任和保密承诺改变后续传授选项，违约影响原人物的关系；只写行记的人遇到读者，而不会被写成已经建立门派。善意不统一转换成定时发奖。

化神圆满后的自动飞升会先停下来询问。选择留下会停止自动叩关，仍可之后手动尝试；决定叩关也不会保证成功。没有飞升率上限、死亡配额或为了故事安排的强制失败。

## 保留的修仙深度

「修行与事务」收纳完整数值、突破明细、境界准备和常用事务，主要页面仍然可达。

- 五个地域、二十门派；门槛、委托、年例、专长、一次性法宝和离宗规则真实生效。
- 七种手动年度重心、三种持续突破准备；成功可获得本世本领，普通突破无需先完成准备。
- 四段三幕地域机缘，支持不同解法、可信同伴、撤退及中途存档。
- 洞府五类设施、行囊、坊市、四张丹方、单槽法宝、同道互动和道侣。
- 三条原有命途及后续回响；年谱、传记、收藏、最多30卷前尘和三个手动存档槽。

四位同代人物持续独立修炼、衰老、离世或飞升。新剧情中的读者、接手者与来访者是有限的事件角色，不是无限生成的家族树或完整社会模拟。

## 时间、操作和保存

「人生」页默认流转，每年进度走满才结算。1×／2×／4×／8×只改变现实播放速度；没有一键跳年、离线补算或按时强制结局。离开人生页、隐藏浏览器标签、打开管理弹窗或进入连续机缘会暂停。

重大抉择必须亲选。「代选小事」可以代答普通机缘；在旧版手动重心模式下开启托管，仍沿用原本的自动修养、营生和冲关策略。空格暂停／继续，Escape关闭弹窗。

v1存档继续兼容，新增生活方向字段可缺省。损坏数据不自动覆盖原档；保留上一份有效备份，导入、覆盖和归隐均需确认。清除浏览器数据会影响本地保存，建议定期导出 JSON。

## 本地开发

```powershell
cd C:\dev\wanxian-life
npm install
npm run dev
```

固定入口 `http://localhost:5188`。双击 `启动万仙之一.vbs` 使用生产预览；先运行 `npm run build` 更新构建。同Wi-Fi手机试玩可用 `tools/start.ps1 -Lan`，它不安装服务，也不等于公网发布。

```powershell
npm run build
npm test
npm run preview        # 与 dev 二选一，占用相同5188端口
npm run test:browser   # 原有功能及完整人生的浏览器回归
npm run test:life      # 新人生主页、关系选择、旧档与多尺寸检查
npm run build:pages    # 输出 .artifacts/pages-site，含 /wanxian/ 子路径
```

静态发布产物可独立进行浏览器检查：

```powershell
$env:STATIC_DIR='.artifacts/pages-site'
npm run test:life
Remove-Item Env:STATIC_DIR
```

测试使用独立浏览器上下文和虚构存档，不读取或覆盖玩家的实际浏览器存档。截图及报告位于 `.artifacts`，不进入源码提交。

## 发布

先完成验证、提交并推送 `main`，然后运行：

```powershell
powershell -ExecutionPolicy Bypass -File tools\publish-pages.ps1
```

脚本从干净源码构建静态站点，以普通快进提交发布到同仓库 `gh-pages`，不强推、不上传密钥或测试存档。首次需将 GitHub Pages 来源配置为该分支根目录。分支推送不等于公网验收完成，仍须检查 Pages 状态、实际页面、图片、创建人生和刷新续玩。

本次公网使用独立静态托管；未新增VPS容器、Cloudflare路由、家中常驻服务或后台智能体。Pages模式明确关闭不存在的模型后端，不让404请求影响游玩。

## 可选本地 StartLux

本地 dev／preview 仍可通过 `.env.local` 配置 `STARTLUX_KEY_FILE` 或 `STARTLUX_API_KEY`，参见 `.env.example`。密钥仅由服务器读取，不进入前端、存档或Git。

StartLux只对已有的合法普通机缘或具体NPC互动候选排序。后台准备未及时完成时，年界或点击立即采用本地结果；迟到回答丢弃。它不生成任意剧情、发放奖励或代替人生决定。公网Pages版不启用该可选服务；两个模式使用同一套核心模拟规则。

## 代码入口

`src/game/lifelines.ts`：人物关系事件、生活方向、长期承诺及真实效果。

`src/game/engine.ts`：确定性年度结算、行动、普通突破和最终选择。

`src/game/story.ts`、`events.ts`：既有命途与生活事件；`progression.ts`、`sects.ts`、`expeditions.ts`：进阶修仙规则。

`src/pages/Journey.tsx`、`LifeJourney.css`：人生主页；`src/components/Birth.tsx`：简洁出生；`App.tsx`：时间、导航、弹窗与存档。

`docs/DESIGN.md`：当前实现与约束；`docs/WORLD.md`：世界设定及已实装边界。
