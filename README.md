# 万仙之一 · 浮生问道

一个独立、原创、中文单机修仙人生模拟 Web App。真实源码位于 `C:\dev\wanxian-life`，与《一方洞天》《修仙宗门》没有代码或存档共用关系。

源码 GitHub 仓库：**https://github.com/happyivanencoding/wanxian**（`main` 分支；后续已验证的项目修改持续提交到此仓库）。GitHub 代码发布不等于游戏网页已经在互联网上部署。

## 启动

双击项目根目录的 **`启动万仙之一.vbs`**，在浏览器访问 **http://localhost:5188**。启动器优先打开已运行的本项目；未运行时启动本地生产预览。它不会创建开机自启、Windows 服务或外网部署。

本机验证环境为 Node.js 24.15.0（测试直接执行 TypeScript）；已安装的依赖版本以 `package-lock.json` 为准：

```powershell
cd C:\dev\wanxian-life
npm install
npm run dev
```

```powershell
npm run build         # TypeScript 检查和生产资源构建
npm test              # 引擎、宗门、导演、服务端/客户端、存档及完整人生模拟
npm run test:browser  # 先运行本地应用；使用本机 Chrome 的独立临时上下文
npm run preview      # 运行 dist，端口同为 5188；不能与 dev 同时运行
```

请始终使用同一地址 `http://localhost:5188`。`127.0.0.1` 和 `localhost` 是不同浏览器存储来源，不会共享存档。

### 同一 Wi-Fi 的手机试玩

在电脑运行下列命令启动局域网模式，终端会显示当前手机网址（`http://电脑局域网IP:5188`）。电脑仍可使用原来的 `http://localhost:5188`。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\start.ps1 -Lan
```

手机和电脑连接同一网络，并保持电脑开机、游戏预览运行。局域网提供页面资源和同源机缘安排接口；完整模拟与存档仍在各自浏览器中。手机存档保存在手机浏览器里，不与电脑自动同步；可通过游戏内JSON导出/导入转移。电脑局域网IP可能随网络变化，重新运行命令可查看最新地址。

默认双击启动器仍仅供本机；`-Lan`是本次用户要求的局域网入口，不会创建开机服务或部署公网网站。若已有只监听本机的预览，脚本会提示先关闭该实例再以`-Lan`启动，不擅自停止其他进程。Windows需要允许Node.js在当前网络接收连接；本次电脑已存在相应入站规则，未新增或修改防火墙设置。

### 可选的 StartLux 机缘安排

StartLux 已接入游戏运行，并在后台准备紧邻下一步可能用到的安排。年度进度流转期间，引擎用当前人物状态预演下一次推进；只有这一年确实会出现需要安排的普通机缘时，才请求它参考经历、地域、师承和关系选择合法候选。进度走满时，有已就绪且仍匹配当前状态的结果便采用；没有就立即按本地规则结算，时光不会等模型。它不生成任意新规则、自由文本剧情或奖励，也不代替玩家选择命途、结道侣及小剧本行动。

核心游戏不需要密钥。要启用联网安排，在电脑服务器端将 `.env.example` 复制为 `.env.local`，只配置下面两种方式之一：

```dotenv
STARTLUX_KEY_FILE=C:/private/startlux-key.txt
# 或 STARTLUX_API_KEY=你的Bamboo密钥
```

示例路径是占位符；填写实际私有文件路径，不把密钥或真实路径写入源码。`.env.local` 已被 Git 忽略，不使用 `VITE_` 前缀。环境配置改变后重启该游戏的 Vite dev／preview；密钥只由电脑读取，手机无需输入。启动器会区分“已配置”“本地规则”以及“旧预览没有接口、需要重启”，不会自动停止其他进程。

固定模型为 `startlux-decision-27b-autothink`，通过 [Bamboo Decision API](https://bamboonode.dev/docs/ai-model/decisions/startlux) 请求。游戏内使用 `think_mode: never`，只给紧邻下一步的合法候选排序；没有候选的普通年份不发送模型请求，不预写长远人生。dev 和 preview 均在原来的 5188 端口提供同源 `/api/director/status`、`/api/director/decide`，不新增后台服务或第二常驻端口。

同道界面的论道、赠礼和切磋按钮在鼠标移入、键盘聚焦或按下时，可为这一次明确的互动提前准备回应，不扫描所有NPC或预取所有按钮。点击始终立即结算；若准备尚未完成，就采用本地回应。同一次费用和效果只结算一次，之后到达的回答不会追补或改写结果。

在「偏好设置」可关闭联网安排，或查看最近一次实际采用 StartLux 还是本地规则。发送内容限于虚构人物的必要状态、最近经历、地域、师承、关系，以及本地预演确认的紧邻一步合法候选；预演不提前改变人物或消耗原随机数，也不向玩家预告故事。不发送完整存档、前尘档案、延后剧情队列、长远未来回报清单或密钥；上下文只包含已知经历及这一步按引擎规则将处理的处境。服务器每次后台请求仍有3秒截止时间，客户端请求也有超时与取消；这不是玩家的等待时间。未配置、断网、限流、超时、回答不合适或结果未及时就绪，都不阻碍本地结算。关闭设置、换页、暂停、读档、重开、另作行动或状态变化会取消不再匹配的准备，迟到结果直接丢弃。

## 现在可以玩什么

- **出生与世界**：五种家世、三种时代、四条修行道路；可随机或指定五洲的出生地域。地域有不同风土、势力、修行适性和机缘入口；家世与出生地分开选择。从零岁或十六岁开始，保留命运种子与预计半小时／一小时设置。宏观设定及首批可玩边界见 `docs/WORLD.md`。
- **修行**：七种年度重心、修为、体魄、道心、根基、悟性、寿元、灵石；进入修行页自动流转，固定的年度进度条走满才结算一年；暂停、1/2/4/8 倍速与托管。不再提供直接跳过一年或十年的按钮。
- **境界准备与突破**：每境可选择行山锻体、典籍推演、药性温养三种持续准备，以相应重心与真实资源逐年投入；当地修行适性改变效率。切换保留本境进度，失败不清空；完成后成功突破，会留下不随属性维护衰减的本世本领。普通突破仍开放，准备不是必做任务。单次机会仍为7%—90%，可展开查看实际贡献，不设结局比例控制。
- **机缘与命途**：守望人间、孤峰问道、山河商路三条因果主线。出身、志向、手艺、行旅和同道关系影响邀约与中段处境；药堂与迁居、残卷与共学、供给与旧账分别留下不同的生活结果。日常经历自动记入年谱，重要转折亲自决定，后续回响自动兑现；可以因迁居转向商路，保留旧誓与经历。
- **山河与身份**：五个可玩地域作为五洲锚点，改变修炼、准备、历练与入宗地点。终卷根据真实师承职级、际遇所得、异法、迁居与行旅描述人物身份。世界设定中的其他城镇是扩展空间，尚未模拟全部大陆和势力政治。
- **仙门**：五个地域各有四门，共20个可加入势力。山门有不同文化、入门费用与门槛、年例、委托回报、专长及独有法宝；凭贡献晋升至传功长老。剑术、药理、阵学、盘账、寻路、炼体本领参与修行和小剧本解法。离宗保留已学专长与所得装备，失去当前门派被动及年例；多门已学专长的同一数值收益取最强项，不靠反复换门无限叠加，同一门专长与法宝每世仅授予一次。
- **主动机缘**：雾隐泉、折梅谷、照夜剑冢、无昼台四段地域小剧本，各有三个连续阶段、不同解法与结局。准备、门派技法和可信同道会改变后续选项与风险。可撤退、保存续玩；入场只占一次主动行动，后续选择不重复扣年度行动。未来回报不提前预告，结果发生后清楚展示实际所得或损失。
- **洞府**：五种设施，每种最高三级；真实修炼/恢复/材料/炼丹增益。当前是设施升级，不是自由摆放编辑器。
- **行囊**：物品筛选、搜索、坊市买卖、丹药服用、法宝装备/卸下、一次性典籍研读与四张丹方。
- **同道**：四位独立成长的同代人物，各有盘账、辨药、寻路或护阵本领。信任足够时能在对应小剧本提供不同办法，共同经历降低再次托付的关系门槛。论道、赠礼、切磋之后会依实际性格、关系、伤势和既往共同经历作出不同回应，产生明确的身心、技艺、关系或资源收益；可由 StartLux 选择，也有本地规则。陨落或飞升后不继续以在世同伴身份回应。
- **此生故事/年谱/前尘**：主页展示当前人生安排、牵挂人物、最近因果及持续影响；年度格图与身心曲线继续逐年记录，普通修行每五年概述当前状态。重要抉择与回响保留详细记录，可搜索、收藏、导出，并写入结局传记。
- **存档**：自动保存、上一份有效备份、三个手动槽、完整 JSON 导入/导出、损坏数据提示；导入与覆盖均有确认。
- **手机交互**：四个底部主入口「修行／机缘／经营／此生」，经营与此生用短子导航保留全部原功能。首页优先显示当前修行、机缘入口与境界准备；人物详情、故事和年谱移到此生，手机完整属性可展开。连续剧情优先显示当前场景和刚得到的成果。桌面保留侧栏，双主题与弹窗焦点约束继续可用。

## 如何开始

点击「开始此生」，选择预计一局半小时或一小时，初次可保留「修行者」和「从十六岁启程」。处理离乡选择后，「修行」页默认自动流转，进度条走满才过一年，无须点击开始，亦不支持直接跳年。基于约800年的人生估算，半小时模式1×每年2.25秒，一小时模式4.5秒；这是按当前模拟样本校准的播放节奏，实际寿命、操作和停顿会改变真实游戏时长，不保证在固定时刻结束。按1×/2×/4×/8×调整时间流速，空格或「暂停/继续」可以随时停止。每年三次行动用于交易、远行、建造、冲关或拜访，下一年自然恢复。

托管会自动调整重心、处理普通机缘和尝试冲关；命途、志向、收徒、禁术等重要决定会停下来等你亲选，选择后继续。日常小事及已选安排的回响会自动记录，不要求年年确认。托管不会代办全部宗门经营和探索。离开「修行」页默认暂停，回到「修行」页恢复流转；打开主要管理弹窗或切换浏览器标签也会暂停。暂停时当前年度进度保留，不补算离线时间。快捷键：空格暂停/继续，Escape 关闭弹窗。

手机从「修行」查看当前安排，点「更换重心」就地选择；在境界准备里选方法，再切换相应重心，投入按年自动进行。托管会照顾已选准备，但不会替你选择一种方法。到「机缘」主动进入已发现的经历；途中时间与无关事务暂停，离开页面或保存再载入仍停在同一场景，可继续或撤退。已学本领集中在「此生」查看。

已有v1存档可继续，旧命途与待决事件不会被删除。用新人物可以从头体验情境邀约；旧人物也会沿已有承诺继续遇见新的处境。药堂的年度供养、研究或行旅心得、商路补给和驿站路费优惠均参与实际引擎结算。

新存档中的准备、小剧本和导演记录字段允许旧档缺省，导入仍先校验再确认。后台准备只保存在当前页面内存，不新增存档字段；读档后不恢复尚未发生的预取结果。旧存档默认开启可选机缘安排，但电脑未配置服务时仍按本地规则运行。最近64条实际安排来源随人物存档保存，已发生的结果不会在载入时重新请求。部分秘境有地域、境界、关系或旧线索条件；错过或完成的经历不会重复刷永久收益。想从出生地开始体验这轮世界差异，可以先保存旧人生，再开启一段新人生。

## 游戏平衡原则

**不为凑出失败结局而人为压低飞升率。** 属性过高会随时间自然回落、修炼及洞府产生真实供养成本、穷困与错误选择会带来负担；良好经营、准备和正确际遇仍可能飞升。不使用失败配额或跨世胜率调节。具体规则见 `docs/DESIGN.md`。

## 数据和边界

所有内容为虚构游戏设定。加载完成后核心游戏计算在浏览器本地运行，无需账号或 API Key，也不请求外部素材。StartLux 是可关闭的联网辅助，仅服务器端需要已授权的 Bamboo 密钥；无法联网不阻止当前已加载页面继续游玩。未实现离线安装的 PWA、云同步、多人联机或服务器账号；断网后重新加载页面不保证资源仍可用。

关闭/刷新页面可以继续游玩；清除站点数据、换浏览器或无痕退出可能丢失记录。请定期导出 JSON。前尘录最多30段人生，单卷最多500条重要/收藏记录；当局普通日志会整理，优先保留重要/收藏记录。

## 本轮验证（2026-10-21）

生产构建、89项自动测试和52项浏览器检查通过，包含2,000段完整人生与桌面／390／360／320px手机流程；浏览器控制台及页面错误为0。预取专项覆盖未完成请求即时回退、已就绪结果单次消费、同一状态和动作去重、切换人生或动作后失效、离线和请求失败。

浏览器测试故意扣住机缘响应不返回：8倍速下按原有时钟推进400ms后，人物已正常进入下一年并使用本地机缘；随后释放回复，已发生结果保持不变。另一场景提前得到回复，在正常年度边界才采用StartLux，准备期间不提前过年或扣资源。NPC点击同样在响应仍被扣住时完成本地结算，迟到回复无法改变新载入的人生。

真实StartLux测试中，手机尺寸浏览器先在后台准备药师回应，期间存档不变；该次后台耗时668ms，随后点击到实际结算约33ms，记录来源为StartLux并只扣一次行动。这是单次观测，不是固定延迟承诺；高倍速或立即点击时可能更常采用本地结果，游戏不为提高模型采用率延长等待。证据在`.artifacts/engine-prefetch-test.log`与`.artifacts/browser/results.json`，生成证据不提交Git。

启动器不注册计划任务或系统服务。源码发布、局域网试玩、公网部署和用户验收分别记录；本项目尚未部署公网试玩站点。
